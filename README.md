# BootCamp-A1 🚀

A comprehensive repository containing all cybersecurity assignments, CLI tools, and technical tasks completed during the bootcamp.

---

## 📁 Repository Structure & Contents

| Directory / Task | Description & Technical Highlights |
| :--- | :--- |
| **`password-strength-checker`** | A C-based security tool that evaluates password complexity, checks minimum length criteria, and verifies character classes using `<ctype.h>`. |
| **`Library and Framewrok Comparison`** | Technical documentation and architectural comparison matrix detailing the core differences between Software Libraries and Frameworks (Inversion of Control). |
| **`Hexadecimal Viewer`** | A CLI tool written in C designed for binary file inspection, extracting raw bytes, and formatting output into Hexadecimal and ASCII views. |
| **`Log File Parser`** | A SOC analyst utility script in C that reads log files line-by-line, filters specific suspicious keywords (like `FAILED` or `404`), and generates summary alerts. |

---

## 🛠️ Requirements & Compilation

All C programs can be compiled using any standard GCC compiler on Linux, macOS, or Windows (via MinGW). 

Example compilation command:
gcc -o program_name source_file.c
